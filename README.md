# iTreeAutomation

A basic Vue 3 boilerplate — **Vite + TypeScript + TailwindCSS v4 + Font Awesome Free**.

## Stack

- [Vue 3](https://vuejs.org/) — `<script setup>` single-file components
- [Vite](https://vite.dev/) — dev server & bundler
- TypeScript — type-checked builds via `vue-tsc`
- [TailwindCSS v4](https://tailwindcss.com/) — via `@tailwindcss/vite` (config lives in [`src/assets/main.css`](src/assets/main.css); no `tailwind.config.js`)
- [Font Awesome Free](https://fontawesome.com/) — CSS webfont; use any free icon with `<i class="fa-solid fa-...">`

## Setup

```bash
npm install
```

## Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the dev server with HMR (default http://localhost:5173) |
| `npm run build` | Type-check with `vue-tsc`, then bundle to `dist/` |
| `npm run preview` | Serve the production build from `dist/` locally |

## Project structure

```
├── index.html            # app entry HTML
├── public/                # static assets copied as-is (favicon, etc.)
├── src/
│   ├── main.ts            # bootstraps Vue, imports global CSS + Font Awesome
│   ├── App.vue             # root component
│   ├── assets/main.css     # Tailwind entry
│   └── components/         # Vue components (WelcomeCard.vue)
└── dist/                  # build output (generated by `npm run build`, gitignored)
```

## Notes

- `dist/` is generated by `npm run build` and is **gitignored**.
- For `.vue` TypeScript support in VS Code, install the **Vue - Official (Volar)** extension.
